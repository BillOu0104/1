# V0.2 物理研究与模型边界

## 原著、观测与假设分开

作者本人在 [Nature 访谈](https://blogs.nature.com/futureconditional/2016/08/19/the-three-body-problem-and-beyond-a-qa-with-liu-cixin/)解释了以三颗太阳和不可预测运动构思小说，并区分科学与科幻推演。本项目据此保留无轨道锁定的三恒星互相扰动。公开的 [Tor / Reactor 合法小说节选](https://reactormag.com/the-three-body-problem-silent-spring-excerpt-chapters-1-3/)只覆盖开篇三章，不能提供所需的三恒星参数表；本次研究不声称从该节选核实了所有天体细节。

“三日凌空 / 三日连珠”等原著叙事只是场景灵感，不足以唯一推导质量、半径、密度、化学组成或内部强度。这里没有可据以引用的原著精确数值，所有计算数值都标为观测参考或工程假设；不使用影视改编数字冒充原著设定。

[ESO 2003 干涉测量及参数表](https://www.eso.org/public/news/eso0307/)提供 A/B 半径约 1.227 / 0.865 R☉、光度约 1.519 / 0.500 L☉ 和 G2V / K1V 光谱分类。其旧质量估计为 1.100 / 0.907 M☉；[NASA Exoplanet Archive 文献汇编](https://exoplanetarchive.ipac.caltech.edu/overview/alpha%20centauri)包含 B 的 0.934 M☉ 等估计，数值随文献与测量改进不同。Proxima 的约 0.12 M☉、0.14 R☉、低光度红矮星性质可参照 [ESO 2016 发现论文](https://www.eso.org/public/archives/releases/sciencepapers/eso1629/eso1629a.pdf)与 [NASA 介绍](https://science.nasa.gov/asset/hubble/proxima-centauri/)。ESO 旧表的 Proxima 光度不是本项目采用的现代约 0.0015 L☉ 量级的精确同一次测量。

[真实系统结构](https://www.nasa.gov/image-article/alpha-centauri-triple-star-system-about-4-light-years-from-earth/)为 A/B 双星和远处的 C，并非小说式近等质量混沌三体。因此默认采用用户允许的 1 / 0.95 / 0.90 M☉ 参考比，±3% 随机化；这是小说风格假设，不是 α Cen 观测轨道，也不是原著质量测定。α Cen 按钮仅换质量中心值，半径/光度仍由主序近似计算，不等同于拟合真实 A/B/C 的全部性质。

## 积分器选择

实现并对比：旧版 Verlet、缓存力的 Verlet、较细步长 Verlet、[Yoshida 1990 四阶组合](<https://doi.org/10.1016/0375-9601(90)90092-3>)、[Dormand–Prince 1980 嵌入式 RK5(4)](<https://doi.org/10.1016/0771-050X(80)90013-3>)的三个容差档。Verlet 缓存相同位置/质量/力参数下的末次加速度，连续步只需一次新力计算；没有假设恒星固定。

固定步长辛方法适合平滑长期轨道，但紧近掠需要非常小的全局步长。Yoshida 的负内部步不能简单用作物理碰撞时间，所以仅保留可注入研究模式。默认采用嵌入式 DOPRI5：每个状态分量使用 `atol + rtol·max(|y0|,|y1|)`，以五阶与四阶差的最大归一化误差决定接受/拒绝。拒绝步不修改天体。

每次提议还限制：

```text
t_dyn(i,j) = sqrt((r²+ε²)^(3/2) / (G·(mi+mj)))
t_cross(i,j) = sqrt(r²+ε²) / |vi-vj|
dt ≤ 0.12 · min(t_dyn, t_cross)
```

上限0.06T₀，下限1e-8T₀，`rtol=1e-9 / atol=1e-12`。固定0.06T₀宏边界让无过载时不同渲染帧率执行相同物理边界；宏内可自适应。**可变步长不具有辛性**；本阶段没有声称实现 IAS15。[REBOUND 文档](https://rebound.hanno-rein.de/integrators/)指出 IAS15 的高阶自适应以及 WHFast 对层级行星结构的适用性；四个天体的浏览器实现选择较简短、可测试的 DOPRI5，未来可加入 IAS15/WASM。

力与能量使用相同 Plummer 软化。每接受步检查相对能量误差（1e-4可信上限）、线动量误差（以初始总标量动量为尺度，1e-8上限）、质心系角动量相对误差（1e-5上限）。不做能量投影、速度归一化或质心纠偏。只有初始生成会移除漂移。逃逸比能量还需超过动能/势能尺度的1e-6保守余量，避免把近抛物线舍入噪声当作明确逃逸。曲线近掠的直线弦若报碰撞而端点未接触，会回退并细分，避免弦穿球的假碰撞。数值失效单独记录；不能把停止原因统称自然解体。

## 潮汐张量、结构与事件

对于行星到恒星的向量 r，叠加：

```text
T_ab = Σ GM [ 3 r_a r_b / (r²+ε²)^(5/2) - δ_ab / (r²+ε²)^(3/2) ]
ω_self² = G Mp / Rp³
risk = max(0, λ_max(T)) / ω_self²
threshold = 2 / 2.44³ + [strength / (ρ Rp²)] / ω_self,SI²
```

3×3对称 Jacobi 求最大**代数**本征值及方向，不能用可能收敛到负压缩本征值的普通幂迭代。各星沿该方向的正伸展贡献用于记录贡献者，最大贡献者记为主导恒星；不是简单选最大总加速度的星。

2.44 是经典均匀流体 Roche 近似系数，来源可参照 Chandrasekhar《Ellipsoidal Figures of Equilibrium》(1969) 的 Roche 模型；该静态假设不等于快速多星掠过时的真实破碎时间。零强度时，在单星 `d=2.44 Rp(Mstar/Mp)^(1/3)` 恰与阈值相等，测试直接检验这一代数一致性。强度项已转换为相同秒/归一化单位，不加倍或放大实际引力来制造事件。

连续两端点超阈值才累计暴露，下降即清零；总暴露至少2/ω_self。风险接近阈值时还令 dt≤0.25/ω_self。模型仍忽略自转、非均匀密度、偏应力、耗散、共振、非线性形变和热效应；渲染扩张环仅为事件反馈，不是碎片物理。潮汐毁灭是可恢复结束原因，包含年、主导恒星、贡献者和风险。单步尖峰、大共模加速度、合成张量抵消均有测试。

## 实验局限

有限 Seed、有限年限、有限时间步及硬件样本不能证明永久稳定。5年筛选天然降低训练窗内早期失败率；20年结果才是窗外观察，并仍有选择偏差。V0.1 对照还含较大的演示碰撞半径与软化，因此必须结合“同初值、同力律”积分器实验阅读结果。详细原始数据见基准文档。
