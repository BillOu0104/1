# V0.3：四体随机初值、星系尺度与引力牢笼

V0.3 保留自适应 DOPRI5、真实四体引力、碰撞/潮汐、Worker、自动重启、现有页面布局和尾迹实现。产品默认星系尺度3×、软牢笼开启。关闭牢笼就是纯牛顿引力，不添加反射墙、轨道锁定或耗散稳定器。

研究对象为 SYKM《三体实时演算 | Three-Body problem》用户提供快照。证据包括：

- `original/project.json`，SHA-256 `982ef336280c59023731a34c6d64a49b4bf0a54c344ff62321410ccf5a31930d`，实际用户控件值与范围。
- `original/unpacked/scene.json` 中 `objects[8].visible.script`，阅读副本 `009_MAIN_visible_script.js`：参数L4–70、约束L617–678、总加速度L719–748、质心L898–913。

原版距离单位为10¹²m、质量单位为2×10²³kg、构造G所用时间单位为31536000s。本项目保持AU / M☉ / T₀与G=1，年份仍为`t/(2π)`，没有沿用原版另行按回调计数的显示年份。

## 四天体随机初始化

`RandomInitializer` 完全替换了V0.2.1扇区恒星加圆形伴星行星的初始化：

1. 三颗恒星独立采样三维球体位置（半径随机，方向各向同性），质量按已保存参考值±3%；没有等边三角形或轨道模板。
2. 拒绝恒星间距<1.5AU或最大/最小间距比>3的初态。速度为随机轴旋转分量加独立三维随机扰动；去质心漂移后，将恒星动能/势能绝对值比限制在随机0.45–0.58。
3. 相对角动量至少达到总标量角动量尺度的0.6，并要求三颗恒星各自相对其他两星的初始轨道能量为负。只约束初态，不在运行中修正轨道或速度。
4. 行星独立采样相对整个系统中心的3.5–7AU随机位置，距任意恒星至少1.2AU。随机速度方向带整体质心切向偏好，幅度为整个系统当前位置逃逸速度的随机0.55–0.8倍。没有宿主星、不使用某颗恒星的圆轨道速度，也不保证它将来长期束缚。
5. 对完整四体再次移除质心位置和整体速度，核查初始多星潮汐风险小于撕裂阈值的十分之一。行星仍为地球质量/物理半径。
6. 最多128次代数拒绝采样；没有候选池、评分、预积分、固定Seed库。耗尽时明确报错，经现有Worker失败恢复/熔断处理，不悄悄换固定构型。

500个固定Seed测试检查束缚、角动量、三维变化、潮汐与质心；行星最近恒星分布覆盖A/B/C，不再固定为A。Seed、质量与尺度共同决定可复现初态。

## 星系尺度

滑块1–10，默认3；下一次手动重置、自动换轮或Worker重新初始化时生效，不重缩放正在运行的轨道。质量控件继续按既有“应用质量并重置”语义工作。新设置兼容原有localStorage schema。

对相同随机初值执行：`x′=kx`，`v′=v/√k`，质量、G、真实物理半径和软化长度保持不变。理论动力学时间随`k^(3/2)`增长，时钟换算、每秒请求的物理时间并未改变。实际碰撞半径相对系统缩小；混沌放大数值差异，所以有限精度下的逐Seed终止时刻不应承诺精确按比例缩放。

提前/常规逃逸门槛从20/100AU变为20k/100k AU，持续确认时间也按动力学尺度乘`k^(3/2)`；交会统计半径为k AU，物理碰撞与潮汐半径保持原值。牢笼尺寸随本轮k变化。相机距离和最大缩放范围随有效尺度调整，保持原有拖动/缩放方式；尾迹采样、容量和时间长度代码未改动。

## 原版牢笼参数与单位换算

UI保留原版数值约定、默认值及范围，旁注给出实际AU/太阳质量换算；不是把这些坐标幂系数直接代入AU。所有数值控件步长0.001，指数允许小数，与原版project.json控件一致。

| 本项目设置     | 原用户键 / 内部键              |   默认值 | 原范围           |
| -------------- | ------------------------------ | -------: | ---------------- |
| cageEnabled    | newproperty60 / constraint_En  |     true | 开关             |
| cageHard       | newproperty66 / hardConstraint |    false | 开关             |
| cageMass (Mc)  | mc / constraint_M              | 15000000 | 100000–100000000 |
| cageK1         | k1 / constraint_k1             |        0 | 0–1              |
| cageRe         | re / constraint_re             |      0.1 | 0.01–0.2         |

| cageRc         | rc / constraint_rc             |      0.2 | 0–6              |
| cageExponent   | expc / constraint_n            |        2 | 1–10             |
| cageHardRadius | newproperty67 / constraint_Rc  |      2.1 | 2.1–10           |

令`L=k·10¹²m/AU≈6.684587k AU`，`Mc☉=Mc·2×10²³kg/M☉`，默认Mc约1.508698M☉。对天体相对四体瞬时质心的距离r，使用无量纲`x=r/L`，总加速度幅度系数`B=G Mc☉/L²`。这使牢笼半径乘k、加速度除k²，保持与牛顿相似变换一致；Mc不是额外的第五颗星，不加入质心分母。

下式f为**带符号向内幅度**，加速度为`−B f(x) q/|q|`，q为天体相对质心的位置。负号内区表示向外斥力。

软模式（按先后顺序）：

```text
x ≤ re                f = −k1 [1 − (x/re)²]²
x > re 且 x > rc       f = k2 (x−rc)^expc
其余                   f = 0
```

硬模式（按先后顺序）：

```text
x ≤ re                f = −k1 [1 − (x/re)²]²
x > re 且 x ≤ rc       f = 0
x > rc 且 x < Rc       f = k2 (x−rc) / sqrt(max(Rc² − (x−rc)², 1e−5))
其余                   f = 100 k2
```

原版分母确实为`Rc²−(x−rc)²`；不是`Rc²−x²`。`rc>Rc`时中性区优先，真正强力切换在rc；`rc<re`时内区优先。软模式不使用Rc，硬模式不使用expc；UI禁用当前模式无效的对应控件。k2=0仅去掉外部束缚，k1>0时仍存在内区斥力。

### 稳定性上的明确差异

原版硬边界和部分逆序半径组合会有加速度跳变；内区k1>0时精确中心方向也不连续。V0.3在原坐标半径宽度0.001内使用五次smoothstep衔接，中心同尺度平滑降为0；过渡带之外保留分段公式和原分母保护。内边界、硬边界及`rc>Rc`实际切换均有连续性测试。这是公开的新数值处理，不伪称与原版边界完全相同。

DOPRI5每个阶段都从该阶段状态计算COM和额外加速度，仍保留原成对牛顿引力。增加牢笼局部加速时间尺度、边界穿越时间限制；原近距离引力/相对速度/潮汐限制和rtol=1e-9、atol=1e-12未放宽。额外4个积分分量也参与同一误差估计。

1000年长跑还定位并修复了旧调度边界问题：被宏步截成小于最小步长的补齐步，若已通过误差检查，不应把它的极小dt当成下一宏步的精度建议。现在保留补齐前建议；真正需要小于精度下限的近掠仍会停止。旧行为曾使1×牢笼样本在868.117年无近接时错误停止，修复后同样本到达1000年；有独立回归测试。

## 约束物理、诊断与生命周期

牢笼是人为、非平方反比的附加场，不代表真空中的四体牛顿系统。它没有摩擦或轨道稳定器，可能增加反复近接，也不能阻止恒星碰撞、行星碰撞或潮汐撕裂。

- 一般净牢笼力不为0，不能要求惯性系动量及仅含牛顿势能的能量不变；相对瞬时质心的角动量仍应守恒。
- DOPRI5同时积分`Ẇ=Σ mi vi·acage,i`与`Ī=Σ mi acage,i`。能量监测改为`E_N(t)−E_N(基准)−W`，动量监测为`P(t)−P(基准)−I`，不把真实外力做功误报为数值失败。保留未修正牛顿能量变化供审计。
- 曲线弦碰撞需要回退重算时，位置/速度和W/I一起回退；拒步不累计做功。专项回归测试覆盖该情况。
- 参数或总开关实时生效，不改变时间、generation或天体状态。修改时重新建立诊断基准并记录事件；之后的能量收支是新参数段的残差。
- 有外区束缚（enabled且k2>0）时，不使用真空逃逸比能判定永久逃逸，避免重启仍可能被拉回的天体。关闭牢笼或仅开启内区斥力时继续两级逃逸。碰撞、潮汐、数值失败与自动重启/冷却/熔断照常。
- App/Worker默认开启牢笼；底层核心若未提供cage配置仍为纯牛顿，便于既有测试/独立数值对照。V0.3牢笼收支诊断要求DOPRI5；固定步长积分器保留用于无牢笼对照，不对未实现收支的替代积分器伪报精度。
- Worker不增加后台任务、候选筛选或新线程；配置只在值变化时发送，暂停/隐藏与背压继续有效。普通重启复用Renderer/Worker。
