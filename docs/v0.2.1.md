# V0.2.1 修复说明与验证

本版本在 V0.2 上修复逃逸、轨迹和调度，停用混沌预筛选，保留 DOPRI5、潮汐、Three.js 场景与既有布局。没有新增文明、音频分析或鼠标无点击跟随，也没有部署或合并 main。

## 逃逸：旧问题与两级判据

旧实现只在超过100 AU后开始累计确认时间。明确的双曲线飞行会长时间空转，且日志缺少可核查的物理量。**100 AU ≈ 0.57755光天；1光天 ≈ 173.14463 AU**，所以照搬“1光天提前”反而会推迟结束。

新实现位于 `physics/detection.ts`，以天体相对**其余天体质心**的位置、速度计算。令剩余总质量为 M、逃逸天体质量为 m：

- `r = x − COM(others)`，`v = velocity − COMVelocity(others)`，`vr = dot(r,v)/|r|`。
- 势能为所有其余天体的软化引力势之和 `Φ = −Σ G mj / sqrt(rij² + ε²)`，不把多星直接替成一个点质量。
- 相对两簇动能按逃逸天体单位质量计为 `K = ½ |v|² M/(M+m)`；比能 `E = K+Φ`，余量 `E/|Φ|`。
- 其余系统的尺度取显著质量天体（≥剩余质量1%）的最大质心距离与质量加权均方根半径的较大值。地球质量伴星不应掩盖恒星逃逸，但其引力势和二阶矩仍计入。
- 要求相对每个显著质量天体都向外分离，并要求 `E > 4 G I / max(r−R,0.01r)³`，I为剩余系统的质量二阶矩。这个非单极场余量是保守估计，**不是对任意未来能量交换的严格上界**。

| 条件                | 提前级                  | 常规级                   |
| ------------------- | ----------------------- | ------------------------ | ----- | ------- |
| 距离门槛            | >20 AU（约0.11551光天） | >100 AU（约0.57755光天） |
| 距离 / 剩余系统尺度 | ≥6                      | ≥3                       |
| 正能量相对余量      | ≥0.25                   | ≥1e-4                    |
| 径向速度            | `vr /                   | v                        | ≥0.6` | `vr >0` |
| 持续确认            | 连续1 T₀，距离单调增大  | 连续1 T₀，距离单调增大   |

证据消失、距离回缩或判定级别变化都会重新计时。远且受束缚、近抛物线舍入误差、向内运动或仍未隔离的多星近掠继续观察；没有“距离足够远就必定终止”的兜底。有限时间判据不能证明混沌系统永久不返回，宁可延后弱证据也不强行结束。

`PhysicsConfig.escapeDistance`、`escapeConfirmationTime` 与 `escapePolicy` 保留代码级配置；默认策略和 AU/光天转换分别在 `types.ts` 与 `parameters.ts`。结束事件记录 star/planet、级别、AU/光天距离、相对/径向速度、比能、余量、隔离度及模拟年份；数值失败仍单独标记 numerical。确认后立即进入已有结束提示和自动重启流程。

## 尾迹：根因、真实采样与内存

V0.2 的 Worker 一次推进多个自适应步，只传最终快照；SceneRenderer 在渲染帧上每隔0.025T₀最多取一个点，且使用显示插值位置。20×时一个 Worker 请求可跨过许多真实弯曲轨道，渲染端用长弦连接它们。512点还按点数截断，无法表示固定模拟时间。主要问题是**历史丢失和传输稀疏**；原镜像环形缓冲的顺序不是主要折线来源，DOPRI5也没有因此降低积分精度。

新数据路径：`接受且通过守恒检查的积分状态 → TrajectoryRecorder → transferable批次 → Trail镜像环形缓冲 → GPU`。

- 保留实际积分端点。速度转角约0.025rad、速度平方变化4%、弦偏差或0.5T₀间隔触发保留；弦容限为 `max(1e-6, min(0.001, 最近天体距离 × 0.0002)) AU`。高曲率和近掠更密集，近直线段减少点数。每批补上最后一个真实端点，暂停不留下过时的尾端。
- 没有样条、额外引力计算、轨道投影或为尾迹修改积分步长。采样发生在每个接受步，渲染频率只影响额外的批次端点，不再限制弯道采样精度。
- Worker固定4096点暂存，正常每请求至多256次积分尝试、4天体；批次只包含本次增量，使用Float64时间和位置，转移ArrayBuffer，不重复发送完整历史。
- 主线程每体最多8192点，CPU约256KiB/体（双份Float32位置+Float64时间），GPU约192KiB/体；四体约1MiB CPU历史、0.75MiB GPU位置，加Worker约160KiB暂存。没有无限数组或每帧数组移位。
- 用时间戳二分选择可见区间，滑块0.1–10模拟年，默认2年；加长可立即显示尚在容量内的旧历史，缩短立即裁切，兼容旧schema并持久化。点数上限优先，极端高密度下不能保证保留满10年。
- GPU仅批量上传改变的区间；隐藏轨迹时仍保留历史，脏区间在实际GPU上传回执后才清除，防止重新显示时缺失历史。
- 每次generation变化清空批次和有效绘制范围；普通重启不重建Worker或Renderer。旧Worker回执仍由epoch隔离。
- 天体保留既有显示插值，尾迹按同一个显示物理时间裁切上界，避免画出比天体更新的未来尾迹；插值点不写入轨迹或物理状态。

## 初始化与计算调度

生产路径恢复V0.1简单Random的扇区位置、随机速度、去质心漂移、有界动能比例及伴星行星初始化。为兼容V0.2质量设置，三颗恒星按参考质量±3%取值；同Seed、同参考质量复现。正式模拟和重启都直接从第0年开始，没有多候选预模拟、评分、加权选择、prefetch队列或筛选定时器。

`InitialConditionGenerator`、模式描述、未来高级生成器入口保留。StructuredChaos/ScreeningJob源码及单元测试仅用于离线历史实验；生产入口不导入，Worker协议也移除了screening消息。

DOPRI5系数、容差、动力学/穿越时间步限制、潮汐时间尺度、守恒可信阈值均未改动。高负载继续减慢模拟而不降低精度。额外修复主线程请求背压：**无tick序号的设置回执不得解除正在等待的tick**，避免快速调节设置时重复排队请求。隐藏/暂停、Worker故障恢复和熔断保留。

冻结V0.2提交 `39d830bdcbf13bc0c4c7e0e799115c42b6303265`；脚本从Git归档原引擎到临时目录，结束清理。数值平台 Node v24.19.0，AMD EPYC 9V45，Linux。

`npm run benchmark:fixes`：固定 `fix-bench-0` 至 `fix-bench-23`，相同Random原始初值，目标10模拟年，20×、0.05秒输入；关闭自动重启。精度组将两版逃逸距离都设为极大，保留真实碰撞/潮汐/数值终止，避免结束时刻变化污染积分比较。预热后交替顺序重复3次，V0.2.1计时包含轨迹记录、批次准备和快照。观察上限按完整批次结束，可能略超过10年；误差是每批次观察的最大值，不是数学上界。

| 指标                 | 结果                                       |

不能据此宣称计算更快；密集轨迹有成本，当前同初值结果支持精度没有退化，耗时总体接近。所有逐Seed/逐轮数据见 [v021.json](benchmarks/v021.json)。

明确逃逸对照：同一个21AU、径向2AU/T₀的地球质量天体与1M☉恒星。V0.2在约6.494模拟年结束；V0.2.1在约0.1623年、23.039AU结束，提前约97.5%。这是可核查的双曲线样例，不代表任意Seed都能获得这个提前比例。另有真正束缚轨道穿过门槛、转向并返回的多周期测试。

64项单元/组件测试全部通过；strict类型检查、默认及`/1/`生产构建、格式/差异检查通过。单元/组件测试覆盖旧版功能、拒步无副作用、近掠精度、两级逃逸、持续确认重置、潮汐判定、连续自动重启、Seed/质量、无筛选定时器、Worker背压、时间窗口/环形绕回/固定内存、隐藏后的GPU上传范围。圆轨道测试在20×、8次低频推进中保留300多个真实点（旧渲染最多8点），最大弦弓高<0.0005AU，在1000px/AU比例下低于0.5px；偏心近掠采样间隔比远场缩小超过100倍。

主线程TaskDuration只计主上下文，不是整个浏览器CPU；Worker任务数据不包括emit外的消息序列化开销，V0.2下一轮筛选也没有算进前台积分列。两版默认初值策略不同，不能把整页差异全部归因于尾迹实现。RAF回调间隔不等于真实GPU绘制帧率。没有Windows/macOS实机GPU、长时间功耗或永久稳定证明。
