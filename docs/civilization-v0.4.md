# V0.4：原版初值、温度、纪元与文明

## 依据、范围与局限

独立实现基于用户提供的 SYKM《三体实时演算》工程及逆向研究。完整逐项映射见 [覆盖清单](civilization-v0.4-coverage.md)，其中说明了 handoff 路径缺失、研究文档主体恢复和直接恢复原始源码的过程。没有分发原版素材或脚本；公式和流程用本项目代码重新实现。

以上传 `project.json` 保存值作为原版参数基准，不混用 JS 声明值、场景保存值。无法在 Linux 验证 Wallpaper Engine 的隐藏图层回调和两个温度写入者的顺序，因此不宣称逐帧等同于原版运行结果。研究文档 §8 的长寿筛选是建议，不是原版功能，本版没有采用。

原版没有人口、科技、资源、等级升级、文明随机发展概率、热容或脱水免疫。本版的“发展”忠实采用存活与年龄增长，不添加伪造算法。加载动画中的“等级评估”不构成机制证据。没有在线排行榜。

## 初始条件

`OriginalRandomInitializer.generate` 保持四体固定设置质量，先生成全部 12 个位置分量，再生成全部 12 个速度分量：

```
position component = (PRNG() − 0.5) × Random Pos Range
velocity component = (PRNG() − 0.5) × Random Speed Range
```

默认 L=2、V=.1，原版范围均 0–4；本项目 L 下限 .001 防止精确重合。四体采用同一分布，没有行星宿主圆轨道、外壳、能量过滤、角动量约束、预模拟或稳定性评分，也不做质心/总动量校正。原版质量不随机，本版恒星质量精确使用现有质量设置，默认 1/.95/.90 M☉，而非原版各 5,000,000 原版质量单位；这是保留用户物理设置的明确适配。

原版单位：位置 10¹²m；时间 31,536,000s；速度 31,709.79198m/s；质量 2×10²³kg。转换为现有 AU/M☉/T₀ 后，再执行 Galaxy Scale 的位置×k、速度÷√k。真实半径、G 与物理年份不变。原版默认行星质量5000单位≈0.000503M☉≈167地球质量，保留可调范围至100000，物理半径继续地球半径；该密度是游戏化输入，不是合理类地行星事实。真实潮汐模型使用实际质量/半径，不能把原版文明距离阈值当成真实洛希极限。

唯一拒绝采样是“真实物理体积重叠”，最多64次；没有温度或潮汐距离预筛选。Custom Seed 是24个直接初值，默认如下（原版单位），每分量[-2,2]：

| 天体 | 位置        | 速度       |
| ---- | ----------- | ---------- |
| A    | 0,1,0       | .05,-.1,0  |
| B    | -.866,-.5,0 | 0,-.05,.1  |
| C    | .866,-.5,0  | .05,0,-.05 |
| 行星 | .05,-.05,0  | 0,0,0      |

原版使用 Math.random，没有整数 Seed。为保留本项目复现能力，注入现有 FNV-1a + Mulberry32，保持抽样顺序。Custom Seed 不消费随机数；PRNG Seed 仅用于随机模式和确定性自动轮次。所有初值参数在下一次重置/换轮生效；本轮实际输入随快照保存，重跑恢复该输入。非法自定义重叠不会让页面启动崩溃，用户仍能打开设置修正。

旧 `RandomInitializer` 仅用于历史比较；生产 Worker 与 Runtime 使用新类。

## 温度

默认选择辐射模型，光度独立设置为[1.5,.5,.1]L☉（各 .001–10），κ默认7（1–10）。距离使用接受的物理位置，不使用渲染插值。温度距离：

```
rho_i = max(distanceAU_i × AU_SI, 0.01 × 10¹²) / (κ × 1.496×10¹¹)
F = Σ 1361 × luminosity_i / rho_i²  [W/m²]
Tbase = (F×0.7/(4σ))^0.25 − 273.15
A = Tbase<0 && F>0 ? 0.3+0.3×min(1,−Tbase/20) : 0.3
Teq = (F×(1−A)/(4σ))^0.25
TC = round2(clamp(Teq−273.15 + 10×sin(physicalTime/0.6), −270,1500))
TK = TC + 273.15
σ = 5.67×10⁻⁸
```

保留原版近距离保护、冰雪反照率、经验振荡和两位小数判断。物理位置 AU 使用 IAU 常数149597870700m；温度公式明确保留原版近似 AU=149600000000m，因此1AU的原版通量与1361存在约2.8×10⁻⁵相对差异。

这不是热惯性模型：温度随当前位置即时变化，无海洋/大气热容、温室、自转、季节或冰量历史。正弦原版依赖墙钟；本版改为接受的物理时间，以保证暂停、重跑和100×一致。1×正常推进时相位相当于活跃模拟秒，超载或暂停不偷偷推进。

可切换旧 Tx 经验模型：

```
q = clamp(0.4/√d1 + 0.3/√d2 + 0.3/√d3, .1,2)
TC = 1190×(q/1.9)² − 220
```

此处 d 为原版距离单位；不使用光度或κ，相关控件禁用。原版同时写两模型的共享温度，消费者最终读谁无法静态确认；本版只有一个明确选择的权威温度。旧模型 UI 不将未参与温度的辐射值冒充模型输入。

Galaxy Scale 的实际距离改变辐射，绝不隐式用κ补偿；牢笼仅通过运动间接改变温度。

## 纪元与天象

原版判定优先级：

1. d<DO 的颗数（默认DO=.3原版单位）→巨日/双日/三日凌空。
2. 无凌空，T<TF（默认−70°C），d>DF（默认2原版单位）的颗数→飞星/双飞星/三飞星。
3. 没有上述事件，−55≤T≤70°C为恒纪元，否则乱纪元。

距离与飞星温度严格比较；恒纪元两端包含。不是天文地平线/共线/遮挡模型，也不证明轨道稳定。日志独立记录凌空与飞星，因此同一状态可同时满足两类天象，主纪元标签仍按优先级显示。

用户要求的防抖/持续时间为明确增补：普通恒/乱纪元默认连续确认.02物理年，范围0–1年，0恢复原版瞬时；特殊天象立即生效，灾难不参与防抖。状态机记录当前开始/持续时间和最近256个已结束纪元。恒纪元内高于70或低于−50的水合状态显示高/低温标记，实际恒纪元区间仍采用设置。

## 文明与时间

物理年仍为接受时间/2π，顶部不受文明Kt影响。原版以帧计数推进年份和诞生计数，无法满足跨帧率复现。本版固定60次虚拟文明回调/物理年，使用实际接受的物理推进；默认连续ceil(50)=50次适宜后诞生（约.833物理年）。Kt只影响文明年份增量：

```
ΔCivilYear = ΔPhysicalYear × (Kt/10)²
```

Kt默认10，范围1–100；修改后从当前时间连续累计，不回溯修改年份。文明寿命保留原版整数 `floor(CivilYear_death)−floor(CivilYear_birth)`，同时保存精确物理出生/死亡/寿命，避免比赛将文明年倍率当成物理寿命。适宜区间为[-100,200]°C（可调），不同于恒纪元区间。存活时适宜计数仍增长；普通距离死亡不清空它，因此可在同一轨道上快速出现后续文明。

回调位置读数采用该接受步的末端状态，跨过的虚拟计数按固定时间顺序处理；时间误差上限为该物理接受步。近距离精度仍由原有 DOPRI5 动力学/误差/潮汐步长约束。每个接受步另外检查极端温度、天象和毁灭，不依赖虚拟计数、React或日志间隔，因此短于一次虚拟回调但出现在接受状态中的灾难仍被捕获。没有以显示曲线插值伪造物理轨道，也没有声称能识别任何两个物理采样之间未解析的事件。

原版文明灾难优先级：经验“大撕裂”距离Ro（默认.21原版单位）→星—行星文明碰撞Cd（默认.2）→恒星间文明碰撞Cd→温度越界。温度死亡保留高温/低温因果，附注按凌空>飞星优先。修复原版未赋值的恒星间距，使用真实距离。

这些距离判据仅结束文明。物理层真实碰撞、持续潮汐撕裂、确认逃逸、数值失败才结束宇宙并决定自动重启。物理结束会立即关闭当前文明，保留真实结束类型，替代原版 rst 跳变一概写逃逸的竞争行为。

水合显示按原版硬编码[-50,70]°C：区间内浸泡/复苏，外脱水。脱水不暂停寿命、不授予温度免疫。多代文明连续编号，出生和同次死亡以相同编号写两条日志，修复原版编号错位。

## 历史、排行与设置

事件包含物理年、文明年、文明编号、事件类型和细节。涵盖诞生、死亡、纪元切换、天象、极端温度、脱水/复苏、参数修改和宇宙开始/结束。关键事件立即写入；dt默认5文明年（1–10）控制非关键存活状态摘要，不吞掉短暂灾难。UI保留原版最近5条。

最近事件512条，最近文明256条，最近结束纪元256条；本轮排行和会话排行各只保留6条已结束文明，按整数寿命降序，平局保留先出现记录。当前存活文明不参榜。宇宙重置清除本轮历史/编号；会话六名及累计文明数单独保留并标识，不跨刷新保存。Worker故障在最后确认状态结束文明，不虚构丢失的运行时间。

记录包含版本、Seed、宇宙编号、文明出生/死亡年、物理寿命、文明寿命、原因、附注和出生/死亡时初值与环境配置哈希。参数修改有事件记录；哈希不能替代完整配置备份；待应用的初值草稿和视觉偏好不改变本轮哈希，重跑不会覆盖视觉设置，公平比赛需同时记录版本和全部物理/初值/文明配置，并禁止中途改动。原版附注的Kt、牢笼、κ、默认规则字母保留，修复依赖字符串格式比较的默认性判断；它不是守恒精度或真实性证明。

`V04_RULES` 统一定义新增数值/布尔参数、项目默认值、范围和作用；所有数值沿用滑块+98px数字输入、范围/步长/非法输入校验与schema v1持久化。原版世界坐标x/y/size适配为信息面板内部有界排版和字号；状态/寿命/五行日志及标题/六名排行透明度都实际作用。原版 Civ Rank 默认关闭，需在设置中打开；中文/英文影响文明信息。默认左右面板仍隐藏，点击时钟显示。

## 实测与验证

`npm run benchmark:civilization` 的原始记录位于 [v04-civilization.json](benchmarks/v04-civilization.json)。每组12个固定Seed、相同当前DOPRI5/软牢笼、3×尺度，100物理年或2秒CPU/轮上限，三组共36轮。旧组保留V0.3.1初值，原版组使用5000单位行星质量，第三组使用原版分布但地球质量以分离质量因素。各组都开启同一环境观察器；这是初始化对照，不伪称冻结旧程序的性能比较。

| 组别               | 100年存活 | 数值失败 | 已结束文明总数 |  总CPU |
| ------------------ | --------: | -------: | -------------: | -----: |
| 旧初始化           |     12/12 |        0 |            120 | 2.520s |
| 原版项目初始化     |     12/12 |        0 |            106 | 2.686s |
| 原版分布、地球质量 |     12/12 |        0 |            106 | 2.771s |

全部寿命为观察窗截尾，下限约100年，**不能判断真实平均/中位寿命，也没有证据证明原版初始化更长寿**。本轮未据此外推500或1000年寿命。最大能量收支残差：旧1.17e−7、原版4.12e−7、地球控制3.09e−7；均在现有可信阈值内，不更改容差。原版组最大环境快照约40KB；旧组约69KB。未变化历史不重复传输。

观察器隔离实验 [v04-observer-cost.json](benchmarks/v04-observer-cost.json)：相同928个接受步、7.771物理年；关闭观察回调16.00ms，开启18.39ms，约增加2.38ms。物理状态逐字相同。这是单次短微基准，有JIT/调度噪声，不代表所有设备固定15%开销。

自动测试覆盖公式、抽样顺序、512 Seed分布、固定Seed、尺度、自定义初值、全部天象、边界、防抖、出生/多代/水合/灾难优先级、同次生灭、整数寿命、有界600代历史、持久化、Worker交接、失败关闭、1×/100×完整物理与文明序列相同。原有物理/轨迹/竞争测试保留。
