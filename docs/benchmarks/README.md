# V0.2 可重复基准

本记录由 `npm run benchmark:report` 从 [数值原始数据](results.json) 与 [浏览器原始数据](browser.json) 生成。

## 方法

冻结 V0.1 提交 `83acfeb12d3405855226e29040ca2ce4994ada16`，原始源码保存在 `benchmarks/baseline/`。数值环境：v24.19.0 / linux / AMD EPYC 9V45 96-Core Processor。固定 Seed 为 `benchmark-v2-0` 至 `benchmark-v2-23`，所有种群使用相同 Seed 列表，但生成策略不同，不是相同初始位置。

内核实验使用前6个 Structured Chaos 原始初值、完全相同的质量/力律/软化，积分5年，只比较积分器，不做预筛选、碰撞/潮汐终止或 Worker 调度。预热一次后计时3次，报告累计内核时间的中位数及范围（包含每步计时开销，不含诊断开销）；每10接受步采样守恒误差，因此是采样最大值，并非严格误差上界。

| 方案                      | 内核ms（3次中位数） | 范围ms        | 接受步 | 最大采样能量相对误差 | 角动量相对误差 |
| ------------------------- | ------------------: | ------------- | -----: | -------------------: | -------------: |
| v01-verlet-dt.002         |              137.47 | 132.78–161.63 |  94248 |              7.90e-4 |       9.55e-15 |
| cached-verlet-dt.002      |               38.48 | 37.55–40.20   |  94248 |              7.90e-4 |       9.55e-15 |
| cached-verlet-dt.0002     |              383.35 | 382.65–392.72 | 942480 |              8.26e-6 |       4.51e-14 |
| yoshida4-dt.002           |               89.28 | 88.84–89.30   |  94248 |              5.22e-7 |       1.62e-14 |
| adaptive-dopri5-rtol1e-7  |                9.30 | 8.87–9.58     |   3722 |              2.20e-7 |        3.20e-9 |
| adaptive-dopri5-rtol1e-9  |               16.64 | 16.08–21.66   |   6703 |              1.92e-9 |       1.34e-10 |
| adaptive-dopri5-rtol1e-11 |               32.91 | 32.14–36.45   |  14294 |             2.88e-11 |       3.34e-12 |

**默认选择 DOPRI5 rtol=1e-9，而非最高步数配置。** 缓存 Verlet 保持旧精度并显著降低成本；单纯将步长缩小10倍成本更高。Yoshida4 在平滑轨道能量上改善，但固定步长难以覆盖任意近掠，负内部步也不宜直接判定碰撞。1e-9相比1e-7增加一定成本，换来约两个数量级的能量误差改善；1e-11成本约翻倍，没有作为默认。辛方法的角动量保存更好，不能声称 DOPRI5 的所有守恒量都胜出；默认容差下观察误差仍很小。

## 系统存活与复杂性

每组24 Seed、每轮观测至20年或首次结束，关闭自动重启。`censored` 表示活到观察窗末，不是已知永久寿命；分位数按20年截尾，达到该值应理解为至少该年限。每0.05现实秒/20×输入观察一次，采用各版本真实步数上限，采样时刻略不同。以下CPU包含实际引擎诊断及终止检测，不含渲染；预筛选CPU单列，不能隐去启动成本。

交会采用恒星对距离进入1AU计一次、离开1.3AU才重新布防；最近邻恒星身份变化作为轨道交换代理，不能等同于拓扑轨道分类或 Lyapunov 混沌证明。观察越久自然可能记录更多交会，种群存活差异也影响此指标。

**未改进项与偏差：** 筛选组20年存活比例低于未经筛选的V0.2组（16/24对17/24）；筛选偏好交互复杂、更多交换，并非最长寿命。筛选组0/24在前5年结束，较低的早期结束比例部分来自5年筛选窗，本来就存在选择偏差，绝不是零失败率保证。V0.1还有大得多的演示碰撞半径/软化，种群结果不能单独证明积分器提升，因此另列同初值同力律的内核实验。V0.2因真实半径更小，行星也可能先潮汐撕裂而非碰撞。原始/筛选V0.2分别观察到1/1次潮汐结束，未人为增强引力。有限样本只支持当前取舍，不证明无限稳定。

## 可靠性验证与复现

`npm test`覆盖椭圆近掠、自适应拒步无副作用、守恒、张量旋转/叠加/Roche密度缩放、单步尖峰抑制、真实潮汐终止及预备初值重启、不同分片预算筛选复现、有限降级、Worker主线程隔离/请求背压/隐藏冻结/故障恢复与熔断、质量设置和旧版交互。

`npm run benchmark` 重跑数值实验；`CHROMIUM_PATH=/usr/bin/chromium npm run benchmark:browser` 重跑浏览器（Linux云环境，需要tar和基线Git历史）；`npm run benchmark:report` 刷新本文。全量JSON包含每个Seed的观察时长、原因、误差和耗时。CI用6 Seed / 8年快速样本输出到测试artifact，不覆盖提交的完整24 Seed报告。
