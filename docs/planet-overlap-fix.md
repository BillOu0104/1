# V0.3.1 修复：行星活动区重叠与紧凑数值输入

本次只修改 RandomInitializer 的行星位置/速度分布，以及通用数值控件排版。恒星质量与生成约束、DOPRI5、引力牢笼、碰撞/潮汐/逃逸检测、自动重启、轨迹与相机保持不变，版本仍为 V0.3.1。

## 原因与修复

旧行星位于相对恒星质心的 3.5–7 AU 外壳，速度方向满足 `|cos(r,v)| ≤ 0.45`，速率为全体恒星共同产生的局部逃逸速率的 0.55–0.8 倍。位置在外、速度接近切向，容易形成外围环三星运动。

新分布将初始半径缩为 **0.8–3.2 AU**，方向仍在三维空间各向同性独立抽样；速度方向不再限制为切向，速率改为全系统局部逃逸速率的 **0.35–0.7 倍**。未指定宿主恒星或圆轨道，没有规定后续穿行路径，也不使用预模拟筛选。

保留距每颗恒星至少 **1.2 AU** 的初始间距、多恒星潮汐风险低于撕裂阈值十分之一、完整四体质心/动量校正和最多 128 次有界拒绝采样。Galaxy Scale 最后执行 `x×k, v/√k`；所有上述初始距离随 k 缩放，物理质量、半径和真实年份换算不变。

同一构建、Seed 和配置继续可复现，**修复前后相同 Seed 的初态会变化**。两版拒绝采样过程不同，同 Seed 的恒星抽样也可能因接受轮次变化而不同；本报告比较整个实际生成器的输出分布，不是冻结恒星的单变量实验。比赛或复现应同时记录提交 SHA，不能只记录 V0.3.1 标签。

旧数值控件采用 `minmax(125px, 1.2fr)`，右侧区域会跟随可用宽度扩大。现统一设数字框为 **98px**，单位使用独立 30px 列以使全部数值框对齐，滑块取得其余宽度。移除占宽的原生鼠标微调箭头，保留数字输入、键盘上下键和验证/双向同步；13 字符以内正常字号，较长安全整数用 9px 字号显示。未逐项修改参数或应用时机。

## 多 Seed 对照

基线冻结提交 `cfc2c2e0fce9d45bf9250c727f076dda3b221b41`。初态各抽样 **1024 Seed**；动态对照每组 **48 Seed × 100 物理年**，1×/3×、牢笼关/开、旧/新生成器共 **384 轮**，统一使用当前生产 DOPRI5、默认参考质量、相同物理参数，关闭自动重启以观察单轮。没有筛选掉不理想结果。

### 初态距离与速度分布

距离在 1× 下为 AU；其他尺度整体乘 k。Rstars 为三颗恒星相对其质心的最大距离，r 为行星到恒星质心的距离。

| 指标               | 旧版 p10 / 中位 / p90 | 修复后 p10 / 中位 / p90 |
| ------------------ | --------------------- | ----------------------- |
| 行星到三星质心距离 | 3.90 / 5.30 / 6.65    | 1.04 / 2.12 / 2.98      |
| 行星到最近恒星距离 | 2.80 / 4.22 / 5.70    | 1.37 / 1.95 / 2.74      |
| r / Rstars         | 1.44 / 2.03 / 2.97    | 0.39 / 0.80 / 1.27      |
| 局部逃逸速率比例   | 0.579 / 0.679 / 0.774 | 0.389 / 0.531 / 0.667   |

初态 r<Rstars：**1/1024（0.10%）→724/1024（70.70%）**。具有明显向内或向外速度分量 `|cos(r,v)|>0.45`：0→570/1024（55.66%）；不再默认排除穿越质心区域的方向。这里的“活动区重叠”是空间尺度统计，不表示行星必然穿过某三角面或长期束缚。

### 轨道接近与远距离驻留

每个真实接受步按 dt 加权记录。近接定义为最近恒星距离 < k AU；远距离为 `r > max(1.5 Rstars, 4k AU)`。下表远距离比例是全部仍活跃物理时间中处于远区的比例，含后来逃逸的时间，不把它冒称为稳定轨道判据。

| 尺度 / 牢笼     | 远距离时间比例 旧→新 | 至少一次近接 旧→新 | 平均近接进入次数 旧→新 |
| --------------- | -------------------: | -----------------: | ---------------------: |
| 1× / 关         |        63.37%→60.34% |        30/48→40/48 |              1.85→3.92 |
| 1× / 开         |        66.41%→62.56% |        42/48→43/48 |              4.56→7.71 |
| 3× / 关         |        53.71%→41.60% |        21/48→40/48 |              1.06→3.31 |
| 3× / 开（默认） |    **54.41%→43.10%** |    **29/48→42/48** |          **1.58→3.81** |

另记录负瞬时牛顿多源轨道比能且位于远区的时间比例；默认组 **43.23%→30.11%**。观察至少10年、80%以上存活时间满足该代理条件的远区主导样本：默认组2/48→0/48，3×无牢笼8/48→2/48，1×无牢笼11/48→7/48。多体瞬时比能不是永久束缚证明，牢笼也可能拉回牛顿比能为正的天体，因此同时保留纯空间比例，未将这些代理分类用于物理结束检测。

### 早期毁灭与存活代价

“行星毁灭”仅指涉及行星的碰撞或潮汐撕裂；逃逸与恒星碰撞分别统计。

| 尺度 / 牢笼 | ≤10年行星毁灭 旧→新 | ≤10年任意终止 旧→新 | 100年内行星毁灭 旧→新 | 行星逃逸 旧→新 | 活到100年 旧→新 |
| ----------- | ------------------: | ------------------: | --------------------: | -------------: | --------------: |
| 1× / 关     |           0/48→0/48 |           7/48→7/48 |             2/48→0/48 |    20/48→27/48 |     21/48→16/48 |
| 1× / 开     |           0/48→0/48 |           0/48→1/48 |             4/48→3/48 |      0/48→0/48 |     39/48→42/48 |
| 3× / 关     |           0/48→0/48 |           0/48→0/48 |             0/48→0/48 |    12/48→11/48 |     36/48→37/48 |
| 3× / 开     |           0/48→0/48 |           0/48→0/48 |             1/48→0/48 |      0/48→0/48 |     47/48→48/48 |

全部384轮无数值失败、无CPU/步数预算截尾；达到100年是观察窗截尾，不是完整寿命。按完整请求批次停止，raw observedYears可能略超100年（最多约0.191年），驻留时间按实际接受步加权。1×无牢笼的行星逃逸增加，平均截尾观测寿命62.21→56.01年，不能声称所有模式寿命提升。1×牢笼新增的≤10年终止是恒星碰撞。有限样本中未见早期行星毁灭不代表其概率为零，也未验证100年以上的新版寿命分布。

原始逐 Seed 初态/结束原因/驻留时间/误差/步数/计时见 [planet-overlap.json](benchmarks/planet-overlap.json)。计时含每个接受步的诊断采样，且云主机曾同时运行自动化验证，只作为本次资源使用记录，不作纯物理核提速结论。

103项单元/组件测试通过。新增500 Seed初态回归检查空间重叠、向内/向外速度与速率范围；原有500 Seed安全/三维约束、700个不同参考质量场景、Seed复现、尺度变换与潮汐检查继续通过。浏览器逐项验证98px输入、跨参数对齐、文本宽度、滑块可用宽度及原有双向同步，覆盖21:9、16:9、窄窗口。
