# 三体实时模拟壁纸 · V0.2

三颗有质量恒星和一颗地球尺度行星的浏览器实时引力模拟。保留 Three.js 全屏场景、21:9 / 16:9 布局、轨迹、相机、时钟和设置；V0.2 将物理及初值筛选移至 Web Worker，并精简默认画面的装饰文字。

## 直接使用 / GitHub Pages

站点地址为 [https://billou0104.github.io/1/](https://billou0104.github.io/1/)，以仓库 Pages 部署结果为准。V0.2 在独立 PR 中，合并前线上版本仍为主线版本。

仓库 **Settings → Pages → Source: GitHub Actions**。合并至 `main` 后，官方 Pages Actions 自动测试、构建并部署；也可在 **Actions → Deploy GitHub Pages → Run workflow → main** 手动运行。私有仓库需支持 Pages 的套餐；普通 Pages 站点通常公开可访问。无需本机安装 Node.js、上传 dist 或配置 PAT。Vite 的部署 base 来自 `configure-pages`，PR CI 会实际检查仓库子路径的脚本、样式和 Worker。

## 运行与验证

需要 Node.js **22.12+**。Windows、macOS、Linux 的应用开发命令相同：

```bash
npm ci
npm run dev
npm test
npm run typecheck
npm run build
npm run preview
```

浏览器回归测试：

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Linux 已有 Chromium 时可用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`。Pages 子路径复现：

```bash
VITE_BASE_PATH=/1/ npm run build
VITE_BASE_PATH=/1/ PLAYWRIGHT_BASE_URL=http://127.0.0.1:4173/1/ npm run test:e2e
```

生产构建默认使用相对路径；Pages 构建使用实际站点路径。**必须经 HTTP(S) 服务访问**，直接双击 HTML 不能可靠加载 ES module Worker。未安装或连接 Wallpaper Engine。

## 使用

- 拖动旋转、滚轮缩放，观察目标跟随恒星质心。未修改或新增“鼠标无点击跟随”。
- 顶部是真实本地系统时间、日期和独立的模拟纪年；点击同时展开/隐藏双侧面板。
- 底部保留静态波形容器；不读取麦克风或系统音频，未实现音频分析。
- 右下齿轮：暂停、速度、自动重启、轨迹、Seed、手动重置和三颗恒星参考质量。质量在参考值附近随机 ±3%，**重置后**生效；α Cen 按钮只采用参考质量，不采用现实轨道。
- 初始筛选在后台进行，显示短暂提示。正式一轮从选中候选的原始初值开始，纪年为零。面板显示筛选合格数及是否降级。
- 恒星/行星碰撞、持续逃逸、行星潮汐撕裂、数值失效都记录原因。默认 2 秒提示后自动换轮，自动重启间至少 8 秒；30 秒内自动重启三次后再次结束会停止重启，需手动解除。
- 下一组通过筛选的初值尽量预先准备；尚未就绪则等待，绝不重复创建 Renderer。最近 200 条实际事件和累计重启数在本次会话中保留；不跨刷新持久化。
- 暂停冻结物理与倒计时；隐藏页面或宿主暂停时停止物理请求及筛选。设置沿用 V0.1 `localStorage` schema；新增质量字段有默认值，旧设置可读取。

## 物理与初值

默认使用 **Dormand–Prince 5(4)**，相对容差 `1e-9`，绝对容差 `1e-12`。步长受局部误差、每对天体的相对穿越时间和引力动力学时间同时约束，近潮汐区还解析行星自身响应时间。宏观时间边界为 `0.06 T₀`，内部步长可降到 `1e-8 T₀`；近远场绝非单一距离开关。优化 Verlet 和 Yoshida4 保留为可注入积分器及基准对照。

自适应 RK **不是辛积分器**；不会承诺无限时间无漂移。每个接受步都检查能量、线动量、角动量；超过可信上限时以数值原因停止，不将其记为真实逃逸/碰撞，也不缩放速度或强行修正轨道。Worker 每次物理请求有 1–4ms 软预算与 256 次尝试上限，超载时丢弃积压模拟时间并显示统计，精度不随负载降低。默认壁纸绘制30FPS、镜头交互60FPS，高负载降至20FPS；画面无变化时跳过 GPU 重绘。

**Structured Chaos** 默认参考质量 `1 : 0.95 : 0.90 M☉`。随机三维位置、共同随机角动量轴与扰动速度，去质心漂移，约束负能量、动能比例、无量纲角动量及恒星间距比。拒绝开局紧双星加远第三星。6 个候选各预模拟约 5 年，按存活、交会、最近邻交换（轨道变化代理）和守恒误差评分，在合格者中 Seed 加权选择。每候选至多 6000 接受步 / 300 个 32 尝试批次；1.5ms 软分片预算让出 Worker，结果由操作上限决定，毫秒预算不改变候选池。无理想候选时选已试者中最长存活者，明确标记降级，不无限搜索。不保证永久稳定或严格的正 Lyapunov 指数。

## 参数与单位：哪些是事实，哪些是假设

- **小说灵感**：三颗太阳的不可预测环境；没有将精确质量、半径、光度、地球密度或抗拉强度伪称为原著数值。
- **天文参考**：α Cen 质量约 `1.10 / 0.94 / 0.12 M☉`；真实系统是双星加远伴星，本项目不复刻其层级轨道。
- **本项目假设**：近等质量主序恒星、非层级混沌构型；半径约 `R☉·m^0.8`，光度采用分段主序近似，颜色由近似有效温度生成，不是任意给三颗太阳涂成红蓝白。行星取地球质量、平均半径和密度。

距离 AU、质量 M☉、`G=1`，`T₀ = sqrt(AU³/(G_SI M☉)) ≈ 58.13 天`，`V₀ ≈ 29.8 km/s`，**模拟年 = 物理时间 / 2π**。1× 每现实秒推进 0.6 T₀，约 0.09549 年。真实时钟独立于模拟。

恒星碰撞用真实估算半径之和；地球物理半径约 `4.26×10⁻⁵ AU`，不再使用 V0.1 演示级大碰撞半径。显示半径另行放大。软化 `1e-6 AU` 远小于恒星半径。逃逸需距离 >100AU、相对其余天体质心向外运动、正相对轨道能量并持续 1T₀；这仍是有限时间启发式，不是永久逃逸证明。

潮汐为多恒星引力梯度张量的最大伸展本征值，比较行星自引力和简化结构强度，参考流体洛希系数 2.44、强度 10MPa（假设）。连续超过阈值至少两个自身动力学时间，单步尖峰不触发。记录时间、主导恒星、多星贡献和风险；行星消失并出现衰减扩张环。**这不是流体/地质破碎计算**，不模拟自转、弹塑性、加热或碎片引力。

完整来源、公式和参数局限见 [物理研究](docs/physics-v0.2.md)。

## 基准、架构与范围

运行 `npm run benchmark` 可复现固定 24 Seed 的数值对照；Linux 云环境 `CHROMIUM_PATH=/usr/bin/chromium npm run benchmark:browser` 可从冻结 V0.1 提取、构建并测量两版浏览器表现，需要 git 历史及 tar。不会部署站点或更改系统设置。

[基准方法与真实结果](docs/benchmarks/README.md)包含原始 JSON、分布、计算成本与未改进项；不能将较小的碰撞半径或预筛选的选择偏差冒充积分器优势。未做 Windows/macOS 实机 GPU 验收。

[架构文档](docs/architecture.md)说明物理、Worker、渲染、设置、事件与宿主适配器。文明、温度、排行、动态音频、HDR、尘埃、Wallpaper Engine 实际宿主连接仍为扩展契约，未实现。V0.1 说明与基线见 [历史文档](docs/v0.1.md)，冻结代码位于 `benchmarks/baseline/`，版本为 `83acfeb`。
