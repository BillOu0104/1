# 三体实时模拟壁纸 · V0.4

浏览器中的四体引力与行星环境模拟。V0.4 独立实现原版壁纸已确认的立方体随机初值、24 分量 Custom Seed、三星辐射/旧经验温度、纪元和天象、文明多代生命周期、日志与寿命排行。保留 DOPRI5、引力牢笼、100× 目标倍速、轨迹、Galaxy Scale 和 Seed 比赛。

[实现与参数说明](docs/civilization-v0.4.md) · [原版功能覆盖清单](docs/civilization-v0.4-coverage.md)。以 SYKM 壁纸的用户提供源码研究为机制参考，未复制或分发原版脚本/素材；不能将游戏化文明模型视为科学文明预测。

## 直接使用 / GitHub Pages

站点地址为 [https://billou0104.github.io/1/](https://billou0104.github.io/1/)，以仓库 Pages 部署结果为准。V0.4 在独立 PR 中，合并前线上版本仍为主线版本。

仓库 **Settings → Pages → Source: GitHub Actions**。合并至 `main` 后，官方 Pages Actions 自动测试、构建并部署；也可在 **Actions → Deploy GitHub Pages → Run workflow → main** 手动运行。私有仓库需支持 Pages 的套餐；普通 Pages 站点通常公开可访问。无需本机安装 Node.js、上传 dist 或配置 PAT。Vite 的部署 base 来自 `configure-pages`，PR CI 会实际检查仓库子路径的脚本、样式和 Worker。

需要 Node.js **22.12+**。Windows、macOS、Linux 的应用开发命令相同：

```bash
npm ci

npm test

npm run build

```

V0.3.1 精度对照：`npm run benchmark:speed`（8 Seed × 1/20/100× × 100物理年）；完整方法、竞赛语义与浏览器性能数据见[本版报告](docs/v0.3.1.md)。

## 使用

- 拖动旋转、滚轮缩放，观察目标跟随恒星质心。未修改或新增“鼠标无点击跟随”。
- 顶部是真实本地系统时间、日期和独立的模拟纪年；点击同时展开/隐藏双侧面板。
- 底部保留静态波形容器；不读取麦克风或系统音频，未实现音频分析。
- 右下齿轮：暂停、速度、自动重启、轨迹显隐及长度、Seed、手动重置和三颗恒星参考质量。质量精确采用参考设置，**重置后**生效；α Cen 按钮只采用参考质量，不采用现实轨道。
- 尾迹长度为 **0.1–10 模拟年**，默认 2 年，立即生效并保存；暂停时也可调整。每颗天体最多 8192 点；高密度时最早历史可能提前淘汰。
- 四体位置与速度全部随机，行星不绑定某颗恒星。默认每次启动/重置/自动换轮使用新 Seed，实际 Seed 可复制复现；固定模式支持确定性自动序列、最大重启次数和重新运行当前 Seed。所有数值设置都有滑块与精确输入框。目标速度最高 100×，显示实际达到倍速，超载保留精度并减慢推进。
- **星系尺度1–10×，默认3×**：下次重置/换轮生效，位置×k、速度÷√k；质量、物理半径、模拟年换算不变。
- **引力牢笼默认开、软模式**：独立分类保留Mc/k1/re/k2/rc/expc/硬模式/Rc，参数实时生效并保存。面板明确显示“非纯牛顿”；关闭即移除额外力。
- 恒星/行星碰撞、持续逃逸、行星潮汐撕裂、数值失效都记录原因。默认 2 秒提示后自动换轮，自动重启间至少 8 秒；30 秒内自动重启三次后再次结束会停止重启，需手动解除。
- 重启时立即用新 Seed 生成简单初值，不重复创建 Renderer 或 Worker。最近 200 条实际事件和累计重启数在本次会话中保留；不跨刷新持久化。
- 暂停冻结物理与倒计时；隐藏页面或宿主暂停时停止物理请求。设置沿用 V0.1 `localStorage` schema；新增质量、尾迹长度、星系尺度和牢笼字段有默认值，旧设置可读取。

## 物理与初值

默认使用 **Dormand–Prince 5(4)**，相对容差 `1e-9`，绝对容差 `1e-12`。步长受局部误差、每对天体的相对穿越时间和引力动力学时间同时约束，近潮汐区还解析行星自身响应时间。宏观时间边界为 `0.06 T₀`，内部步长可降到 `1e-8 T₀`；近远场绝非单一距离开关。优化 Verlet 和 Yoshida4 保留为可注入积分器及基准对照。

自适应 RK **不是辛积分器**；不会承诺无限时间无漂移。每个接受步都检查能量、线动量、角动量；超过可信上限时以数值原因停止，不将其记为真实逃逸/碰撞，也不缩放速度或强行修正轨道。Worker 每次物理请求有 1–4ms 软预算与 256 次尝试上限，超载时丢弃积压模拟时间并显示统计，精度不随负载降低。默认壁纸绘制30FPS、镜头交互60FPS，高负载降至20FPS；画面无变化时跳过 GPU 重绘。

生产默认使用 **OriginalRandomInitializer**：四个天体在每轴 `[-L/2,L/2)` 随机位置、`[-V/2,V/2)` 随机速度；先 12 次位置抽样，再 12 次速度抽样。默认 L=2、V=.1，1 位置单位=10¹²m，1 速度单位≈31709.79m/s。质量由设置精确指定，不随机扰动；不消除原版初值的质心漂移，不做能量、温度、角动量或寿命筛选。仅为数值有效性排除真实体积重叠，随机模式最多重抽 64 次，自定义重叠显示错误。Galaxy Scale 最后执行相似变换。旧 RandomInitializer 仅留作历史基准，不是生产默认。

“Custom Seed”与固定 PRNG Seed 是两个概念：前者直接使用 24 个初始位置/速度分量，后者保证随机抽样和自动轮次可复现。两者都保留 Galaxy Scale 和自定义恒星质量。

文明、温度和纪元在 Worker 内按实际接受的物理状态推进；暂停一起冻结。普通纪元有可调连续确认，灾难和天象不等待 UI 帧。文明死亡不会重启宇宙。文明日志、已结束文明、已结束纪元分别上限 512/256/256；本轮榜和会话榜各保留前六名。排行榜默认按原版关闭，可在设置中开启；物理年与可调 Kt 的文明年分开显示。

运行 `npm run benchmark:civilization` 可复现旧初始化/原版初始化/地球质量控制的 36 轮对照及观察器开销；`npm run benchmark:civilization:soak` 进行4轮千年观察；`npm run benchmark:browser:civilization` 比较冻结V0.3.1与本版浏览器成本，数据在 `docs/benchmarks/v04-*.json`。这些是有限观察窗与 CPU 预算内结果，不推断无限寿命。

## 参数与单位：哪些是事实，哪些是假设

- **小说灵感**：三颗太阳的不可预测环境；没有将精确质量、半径、光度、地球密度或抗拉强度伪称为原著数值。
- **天文参考**：α Cen 质量约 `1.10 / 0.94 / 0.12 M☉`；真实系统是双星加远伴星，本项目不复刻其层级轨道。
- **本项目假设**：近等质量主序恒星、非层级混沌构型；半径约 `R☉·m^0.8`，渲染光度/颜色保留主序近似；温度模块的辐射光度使用独立原版设置 1.5/.5/.1 L☉，颜色由近似有效温度生成，不是任意给三颗太阳涂成红蓝白。行星物理半径保留地球值；V0.4 默认质量采用原版项目 5000×2×10²³kg（约167地球质量），这是原版游戏参数，密度并非地球密度；可在原版初始条件中修改。

距离 AU、质量 M☉、`G=1`，`T₀ = sqrt(AU³/(G_SI M☉)) ≈ 58.13 天`，`V₀ ≈ 29.8 km/s`，**模拟年 = 物理时间 / 2π**。1× 每现实秒推进 0.6 T₀，约 0.09549 年。真实时钟独立于模拟。

牢笼提供额外径向加速度，不能保证永久稳定。开启外区束缚时暂停真空逃逸判断；用同步积分的外力做功/冲量监测收支，避免误报数值失败。关闭后恢复纯牛顿诊断。公式、原版研究来源、单位换算与边界平滑差异见[V0.3说明](docs/v0.3.md)。

恒星碰撞用真实估算半径之和；地球物理半径约 `4.26×10⁻⁵ AU`，不再使用 V0.1 演示级大碰撞半径。显示半径另行放大。软化 `1e-6 AU` 远小于恒星半径。1×纯牛顿时提前逃逸门槛 **20 AU ≈ 0.116 光天**，常规门槛 **100 AU ≈ 0.578 光天**；两级均要求相对其余天体质心的向外运动、正能量余量、多体隔离及持续确认 1T₀。提前级更严格，弱证据继续观察，距离本身不构成结束原因。日志记录天体种类、距离、相对速度及比能；尺度k下距离门槛乘k、确认时间乘k^1.5；开启外区牢笼时停用这项真空判据。这仍是有限时间启发式，不是永久逃逸证明。

潮汐为多恒星引力梯度张量的最大伸展本征值，比较行星自引力和简化结构强度，参考流体洛希系数 2.44、强度 10MPa（假设）。连续超过阈值至少两个自身动力学时间，单步尖峰不触发。记录时间、主导恒星、多星贡献和风险；行星消失并出现衰减扩张环。**这不是流体/地质破碎计算**，不模拟自转、弹塑性、加热或碎片引力。

完整来源、公式和参数局限见 [物理研究](docs/physics-v0.2.md)。
